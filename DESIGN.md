# FINAL DESIGN PROMPT — ADHAM BAARIGH PORTFOLIO

Design a high-fidelity personal developer portfolio website for Adham Baarigh.

The website must communicate personality, craftsmanship, and technical creativity through an elegant editorial design.

## 1. Core Identity

Name: Adham Baarigh  
Role: Full Stack Web & Flutter Developer  
Location: Indonesia  
Personal tagline: "Building digital experiences with purpose."

The website should feel like a carefully art-directed personal website, not a generic developer template.

## 2. Art Direction

Design style:
- Elegant editorial minimalism.
- Contemporary Swiss-inspired layout.
- Asymmetric split compositions.
- Strong typographic hierarchy.
- Generous whitespace.
- Subtle visual details.
- Natural photography.

Color palette:
- Warm ivory: #F7F6F2
- Charcoal: #20211F
- Muted gray: #777873
- Muted blue: #7886A8
- Soft border: #E5E3DC

Typography:
- DM Sans for body text and navigation.
- Instrument Serif for selected headlines.
- Use typography intentionally, not decoratively.

Avoid:
- Purple and blue gradient backgrounds.
- Glassmorphism.
- Excessive rounded cards.
- Floating decorative icons.
- Generic AI illustrations.
- Repetitive three-card layouts.
- Excessive animation.
- Fake statistics and fake testimonials.

## 3. Desktop Layout

### Navigation
Minimal horizontal navigation.

Left:
ADHAM BAARIGH

Right:
WORK / ABOUT / CONTACT

Include a subtle availability indicator.

### Hero — Editorial Split

Use an asymmetric two-column layout.

Left column:
Small uppercase label: "HELLO, I'M ADHAM"

Large editorial headline:
"Building digital experiences with purpose."

Supporting text:
"I'm a Full Stack Web & Flutter Developer who enjoys turning ideas into thoughtful, functional, and user-friendly digital products."

Actions:
- Explore My Work
- Get in Touch

Additional detail:
Based in Indonesia.

Right column:
A large portrait photograph placeholder with an editorial crop and subtle framing.

Use a real portrait placeholder, not an AI-generated avatar.

Include restrained supporting typography such as:
"DESIGN / DEVELOP / CREATE"

Heading:

Personal introduction.

### Contact

Section label: "04 — GET IN TOUCH"

Large headline:

### Footer

Minimal footer with name, copyright, and social links.

## 4. Mobile Design

Create a dedicated mobile layout.

Requirements:
- Compact navigation.
- Hero content stacked vertically.
- Portrait placed below or beside the introduction depending on available width.
- Project images full width.
- Comfortable text sizes.
- No horizontal overflow.
- Touch-friendly links.
- Consistent spacing.

## 5. Interaction

- Smooth anchor navigation.
- Subtle image hover effects.
- Underline or opacity transitions for links.
- Gentle reveal animations.
- Respect reduced-motion preferences.

## 6. Final Design Quality

The result must look like an independent developer's personal portfolio with a distinctive visual identity.

Prioritize composition, typography, imagery, content, and consistency.

Do not invent work experience, client names, achievements, or project statistics.

Deliver:
1. Complete desktop homepage.
2. Complete mobile homepage.
3. Consistent reusable visual components.
4. Project showcase variations.
5. Contact and footer sections.

The final design should be sophisticated, restrained, memorable, and genuinely personal.
